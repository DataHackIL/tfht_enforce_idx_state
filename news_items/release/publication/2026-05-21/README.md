# news_items

This release contains metadata-only rows about Israeli news items related to trafficking, prostitution, brothels, pimping, enforcement, and related legal developments.

## Included files

- `news_items.parquet`
- `news_items.csv`
- `SCHEMA.json`
- `SCHEMA.md`

## Public-data constraints

- no article full text
- no cached HTML or page snapshots
- rows that are suppressed or fail privacy/review gating are excluded
- rights class for public rows is `metadata_only`
